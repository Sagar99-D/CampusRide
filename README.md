# CampusRide v2 – Campus Shuttle Tracker (Prototype)
Just open `index.html` — works fully offline (custom SVG campus map, no libraries).
- Home: animated bus illustration + live fleet stats
- Track Bus: pick From/To (or tap two buildings on the demo campus map) → nearest bus, ETA, seat colour
- Seat Counter: IR Sensor A/B demo (A→B enter, B→A exit)
- Admin: add/remove buses, capacity, start/stop. Saved in localStorage.
Demo campus: Main Gate, Library, CSE & Mechanical Depts, Admin Block, Auditorium, Medical Centre, Canteen, Boys/Girls Hostels, Sports Ground.
